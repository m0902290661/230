錯誤代碼：unable to open for writing 解決方式：

若將程式移至桌面執行尚未能解決問題，請嘗試以下方式

1. 權限不足 (最常見)

如果你嘗試將影片下載到系統資料夾（如 C:\ 根目錄或 Program Files），Windows 會拒絕寫入。

試著用 管理員權限 開啟

2. 防毒軟體攔截

Windows Defender 或第三方防毒軟體（如 Avast, Norton）有時會將 Python 的寫入行為誤判為惡意程式（勒索軟體保護）。

解決方法： 檢查「Windows 安全性」>「病毒與威脅防護」>「管理勒索軟體保護」，看看是否開啟了「受控資料夾存取權」。如果是，請將其關閉或將 Python 加入白名單。

3. 磁碟空間已滿

這點雖然聽起來很蠢，但下載高畫質影片（如 4K）非常佔空間，如果硬碟滿了也會報這個錯。
